## 📌 一、 作業核心資訊速覽

* **作業主題**：多輸出學習 (Multi-output Learning)
* **核心資料集**：`SemEval 2014 Task 1`（句子對語義關係）
  * **訓練集**：4,500 筆
  * **驗證集**：500 筆
  * **測試集**：4,927 筆
* **任務輸入**：前提句 (`premise`) 與 假設句 (`hypothesis`)
* **任務輸出**（同一個模型同時輸出兩個任務）：
  1. **子任務 1（迴歸 Regression）**：相關度分數 `relatedness_score`（連續值 $1.0 \sim 5.0$，評估指標：**Pearson correlation**）
  2. **子任務 2（三分類 Classification）**：蘊涵關係 `entailment_judgement`（類別 `0`: 中立 NEUTRAL, `1`: 蘊涵 ENTAILMENT, `2`: 矛盾 CONTRADICTION，評估指標：**Accuracy**）
* **總分架構**：
  $$\text{總成績 (100\%)} = \text{程式實作 (40\%)} + \text{測試集表現 (10\%)} + \text{書面報告 (50\%)}$$

### TODO 1：DataLoader 與 `collate_fn`
* **輸入**：一個 batch 的字典列表，每個元素含 `premise`, `hypothesis`, `relatedness_score`, `entailment_judgement`。
* **處理方式**：
  - 使用 `tokenizer(premises, hypotheses, padding=True, truncation=True, return_tensors="pt")`。
  - 將 `relatedness_score` 轉為 `torch.float` tensor（形狀：`[batch_size]` 或 `[batch_size, 1]`）。
  - 將 `entailment_judgement` 轉為 `torch.long` tensor（形狀：`[batch_size]`）。
* **回傳**：通常包成 `(inputs, labels_regression, labels_classification)`。

### TODO 2：模型架構 (`MultiLabelModel`)
* **核心骨幹**：`BertModel.from_pretrained("google-bert/bert-base-uncased")`
* **分類與迴歸頭**：
  - 提取 `[CLS]` 標記的輸出（例如 `outputs.pooler_output` 或 `outputs.last_hidden_state[:, 0, :]`）。
  - 可加上 Dropout 防止過擬合：`nn.Dropout(0.1 ~ 0.3)`。
  - **迴歸頭**：`nn.Linear(hidden_size, 1)`（輸出單一數值）。
  - **分類頭**：`nn.Linear(hidden_size, 3)`（輸出 3 個類別的 Logits）。

### TODO 3：優化器與損失函數
* **優化器**：`AdamW(model.parameters(), lr=3e-5, weight_decay=0.01)`。
* **損失函數**：
  - 迴歸任務：`nn.MSELoss()` 或 `nn.SmoothL1Loss()`。
  - 分類任務：`nn.CrossEntropyLoss()`。
* **評估工具**：
  ```python
  psr = load("pearsonr")
  acc = load("accuracy")
  ```

### TODO 4：訓練迴圈
* 原生 PyTorch 步驟：
  1. `model.train()`
  2. `optimizer.zero_grad()`
  3. `pred_reg, pred_cls = model(**input_text)`
  4. 計算各任務 Loss：
     $$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{regression}} + \lambda \cdot \mathcal{L}_{\text{classification}}$$
     *(可嘗試調整權重 $\lambda$，預設相加即可)*
  5. `loss.backward()`
  6. 可加入梯度裁剪防梯度爆炸：`torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)`
  7. `optimizer.step()`

### TODO 5：驗證迴圈與保存模型
* `model.eval()` 配合 `with torch.no_grad():`。
* 累積整個驗證集的預測結果與 Ground Truth：
  - 迴歸：`pearson_corr = psr.compute(predictions=..., references=...)['pearsonr']`
  - 分類：`accuracy = acc.compute(predictions=..., references=...)['accuracy']`
* 綜合指標：$\text{score} = \text{pearson\_corr} + \text{accuracy}$
* 當 $\text{score} > \text{best\_score}$ 時：
  - 確保目錄存在：`os.makedirs("./saved_models", exist_ok=True)`
  - 儲存：`torch.save(model.state_dict(), "./saved_models/best_model.ckpt")`

### TODO 6：測試迴圈
* 載入權重：
  ```python
  model.load_state_dict(torch.load("./saved_models/best_model.ckpt", weights_only=True))
  ```
* 於測試集推論，計算並印出測試集的 Pearson 與 Accuracy。
* **截圖保存該輸出畫面**，準備放入報告最後一頁。

## 💡 七、 報告高分技巧 (Tips for Bonus & High Score)

1. **表格化呈現 (Textual / Tables)**：
   - 範本中有註明：「*For ease of grading, you are encouraged to present data in textual form rather than as images.*」
   - 模型效能比較（BERT vs RoBERTa vs GPT-2 vs 單任務 BERT）請統一整理成清晰的 Markdown / Word 表格對照，方便助教評分。
2. **多輸出好處的深入論述**：
   - 探討相關度（連續語義相似）與蘊涵（離散邏輯判斷）兩者間的相關性。
   - 說明多輸出學習能發揮**隱式正則化 (Implicit Regularization)** 的效果，迫使 BERT 的 Encoder 學到兼具語義關聯與邏輯推理能力的通用表徵，減少單一任務上的過擬合。
3. **深入的錯誤分析 (Error Analysis)**：
   - 不要只寫空泛的「模型在難的句子表現不好」，具體列出 2~3 個預測失誤的樣本對（Premise & Hypothesis）。
   - 分析原因：例如長難句從句解析錯誤、雙重否定引發判斷失準、或是特定領域詞彙缺乏等。
