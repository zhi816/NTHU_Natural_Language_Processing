### 1. TODO 2：資料標籤遮罩（Data Masking，Cell 7）
* **核心理論**：
  在自回歸模型中，輸入是完整算式加答案（例如 `(10+4)*2=28<eos>`），但模型**不能去預測等號之前的算式**。因此等號 `=` 之前（包含等號本身）在 Label 序列中全部補上 `<pad>`（ID 為 0），只有答案字元與結尾保留真實 ID。
* **效能關鍵**：
  訓練集有 **1,000,000 筆資料**！若使用慢速的 `.apply()` 會卡住十幾分鐘。採用下方的 Python 列表推導式只需 **約 15 秒** 即可完成！

```python
# ==================== Cell 7：高效率資料前處理與標籤遮罩 ====================
pad_id = char_to_id['<pad>']
eos_id = char_to_id['<eos>']

char_id_lists = []
label_id_lists = []

# 直接以 Python 原始 list 遍歷處理 100 萬筆，效能極高
src_list = df_train['src'].tolist()  # 注意：Cell 3 已將 tgt 拼進 src
tgt_list = df_train['tgt'].tolist()

for full_str, tgt_str in zip(src_list, tgt_list):
    # 1. 模型輸入序列：整串算式 + 答案 + <eos>
    char_ids = [char_to_id[c] for c in full_str] + [eos_id]
    
    # 2. 算式題目長度（不含答案的字元數）
    prompt_len = len(full_str) - len(tgt_str)
    
    # 3. 標籤序列：等號前全部遮罩為 pad_id，等號後保留答案真實 ID 與 eos_id
    label_ids = [pad_id] * prompt_len + [char_to_id[c] for c in tgt_str] + [eos_id]
    
    char_id_lists.append(char_ids)
    label_id_lists.append(label_ids)

# 將處理好的 ID 序列存回 DataFrame
df_train['char_id_list'] = char_id_lists
df_train['label_id_list'] = label_id_lists

df_train.head()
```

### 2. TODO 4：自回歸答案生成（Generation in `CharRNN`，Cell 15）
* **核心理論**：
  這是當代大型語言模型（ChatGPT、Claude、Llama）在生成文字時的**底層自回歸（Autoregressive）演算法**。
  1. 輸入當前字元序列 ➔ 模型前向傳播。
  2. 為什麼拿**最後一個時間步 `y[-1]`**？因為最後一個時間步的隱藏狀態總結了前方所有文字資訊，代表「當下預測下一個字」的分佈。
  3. 使用 `argmax` 取出機率最高的字元 ID。
  4. 若生成 `<eos>` 則立即結束（`break`）；否則 `append` 進字元清單，滾雪球進入下一輪迭代。

```python
# ==================== Cell 15 內部的 generator 函式 ====================
def generator(self, start_char, max_len=200):
    # 將輸入字串（例如 '10+4='）轉換為 ID 清單
    char_list = [char_to_id[c] for c in start_char]
    
    next_char = None
    
    while len(char_list) < max_len:
        # 1. 將當前 char_list 打包為 Tensor 並增加 batch 維度 (1, seq_len)
        device = next(self.parameters()).device
        input_tensor = torch.tensor([char_list], dtype=torch.long, device=device)
        input_lens = torch.tensor([len(char_list)], dtype=torch.long)
        
        # 2. 送入模型進行推論 (調用 encoder)
        out = self.encoder(input_tensor, input_lens)
        
        # 3. 取出最後一個時間步的輸出 logits (維度: vocab_size)
        y = out[0, -1, :]
        
        # 4. 使用 argmax 取得下一個最可能的字元 ID
        next_char = torch.argmax(y, dim=-1).item()
        
        # 5. 若預測出結束符號 <eos>，立即中斷生成
        if next_char == char_to_id['<eos>']:
            break
        
        # 6. 將預測字元加入清單，自回歸進入下一輪預測
        char_list.append(next_char)
        
    return [id_to_char[ch_id] for ch_id in char_list]
```

### 3. TODO 5 & 6：訓練與損失函數設定（Cell 16, 17, 19）
* **核心理論**：
  * **`ignore_index=char_to_id['<pad>']`**：必須設定！告訴 PyTorch 忽略所有遮罩的 `<pad>` 位置，模型才不會浪費容量去預測無意義的佔位符號。
  * **展平（`.view(-1, ...)`）**：PyTorch 的 `CrossEntropyLoss` 要求輸入為 `(N, C)` 與 `(N,)`，因此必須將 `(Batch, SeqLen)` 展平成一維。
  * **梯度裁剪 (`clip_grad_value_`)**：**書面報告第 5 題必考**！RNN 經過多次時間步展開，梯度反向傳播時矩陣連乘極易引發數值溢位（梯度爆炸），必須強行限制梯度上下限。

```python
# ==================== Cell 16：硬體裝置設定 ====================
```

```python
# ==================== Cell 17：損失函數設定 ====================
```
