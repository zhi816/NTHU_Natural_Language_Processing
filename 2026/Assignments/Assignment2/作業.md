### TODO 2：Data Preprocessing（5%）
* **位置**：Cell 7 (第 5 個 Code Cell)
* **目標**：產出 `char_id_list`（模型輸入）與 `label_id_list`（訓練標籤）。
* **核心邏輯**：
  * **Input 序列**：完整算式 + 答案 + `<eos>`，例如 `'1+2='` + `'3'` + `'<eos>'` $\to$ `['1', '+', '2', '=', '3', '<eos>']` 轉 ID。

* **實作 `generator(self, start_char, max_len=200)`**：
  * 傳入算式字串（例如 `"1+1="` 或 `"(10+4)*2="`）。
  * 自回歸生成步驟：
    1. 將字串轉為 Token ID Tensor 送入模型。
    2. 取最後一個時間步輸出（logits）經 `argmax` 取得預測字元 ID。
    3. 若為 `<eos>` 則立即 `break` 結束生成。
    4. 若非 `<eos>`，將字元加入序列，持續自回歸預測直到 `<eos>` 或達到 `max_len`。
